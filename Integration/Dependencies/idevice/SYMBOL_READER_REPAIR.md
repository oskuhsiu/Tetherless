## One discriminating change

Install the official `llvm-tools` component for exactly Rust `1.98.1` using the
existing official rustup, only in the `apple-producer` matrix lane. The rustup
book documents `llvm-tools`; the official installed distribution metadata maps
that name to `llvm-tools-preview`. No moving toolchain, third-party LLVM, Cargo
package or curl installer is used. The reader is not found via arbitrary PATH
or Xcode: the reviewed compiler reports its sysroot, and the reader must be
`lib/rustlib/aarch64-apple-darwin/bin/llvm-nm` within that sysroot, with exact
installed component ownership. Both compiler and reader must report LLVM 22.1.8. The reader permits only an
empty version suffix or the exact `-rust-1.98.1-stable` suffix generated by
Rust 1.98.1 bootstrap, and retains the complete version text unchanged.

`record_toolchain.py --symbol-reader` records the compiler and reader paths,
SHA-256 digests and full version text, plus component metadata hashes. Each
Apple target re-observes these under the existing bounded supervisor and must
match the lock exactly. The full Rust and C archives are passed to that absolute
reader with external/defined/just-symbols flags, equivalent to `-g -U -j`.
Reader and metadata hashes are rechecked immediately around both scans. There
is no bitcode exclusion, member extraction/filter, swallowed exit code or
partial-output acceptance. After successful supervision, acceptance reads and
hashes each complete bounded log on disk, never the supervisor's 128 KiB summary
tail. A portable output-over-128-KiB regression covers early required names,
old aliases and cross-provider collisions.

The consumer checks the authenticated retained reader receipt against the
retained toolchain lock, Rust compiler identity, version-command logs/statuses
and exact full archive scan commands/statuses. Producer-local paths are only
compared as provenance text, never executed by the consumer. Its existing
observer additionally verifies the actual selected archive hashes and link
commands. It does not rebuild Rust, install a reader or repeat a symbol scan.
Old artifacts lacking this identity evidence fail the new input contract.
